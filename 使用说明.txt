本地 LLM 文档翻译器 - 使用说明
================================

【快速开始】
1. 双击根目录下的「启动翻译器.bat」。
   - 第一次运行会自动创建 Python 虚拟环境并安装所需依赖库，需要联网，
     完成后会记住环境，之后启动会很快。
2. 在弹出的窗口中：
   - 在「翻译设置」中选择「源语言」「目标语言」「模型」「翻译风格」。
     翻译风格除「通顺」「直译」外，新增「wild」：在不改变原意的前提下，
     用更生动、更口语化、更"攒劲"的表达进行翻译，适合成人向字幕翻译场景。
     这些设置会应用于队列中的所有文件。
   - 需要中英对照时勾选「同时输出双语对照」。
   - 在「文件队列」中点击「添加文件...」（支持 .txt / .md / .docx / .pdf / .srt，
     可一次多选），或点击「添加文件夹...」一次性加入该文件夹下所有支持的文件
     （例如一次性加入 20 个 .srt 字幕）。
     也可以直接把文件拖到「启动翻译器.bat」图标上，会自动加入队列。
   - 如需调整，可选中某一行后点击「移除选中」，或「清空队列」重新添加。
3. 点击「开始翻译」，程序会按队列顺序逐个文件翻译，可在「队列进度」中看到
   当前是第几个文件，进度条显示当前文件的翻译进度。

每个文件的输出会出现在 Data\output\ 目录下，文件名格式：
   原文件名.源语言-to-目标语言.translated.扩展名     （纯译文）
   原文件名.源语言-to-目标语言.bilingual.扩展名      （双语对照，可选）

每个文件的任务日志保存在 Data\logs\ 目录下，按原文件名单独生成。


【关于本地模型（Ollama）】
本程序通过本地运行的 Ollama 调用大语言模型进行翻译，不会上传任何内容到云端。

- 已为你安装好 Ollama，并下载了默认模型 qwen2.5:14b-instruct（约 9GB）。
  这是一款 14B 量级的模型，翻译质量比 7B 版本更好，在 RTX 5070 Ti（16GB
  显存）上可以流畅运行，安装后已自动设为「模型」下拉框中的默认选项。
- 另外还保留了体积更小、速度更快的 qwen2.5:7b-instruct（约 4.7GB），
  如果觉得 14B 翻译速度偏慢，可以在「模型」下拉框中切换为 7B。
- Ollama 安装后会在后台自动运行（系统托盘有图标）。如果 GUI 提示
  "未能连接本地 Ollama 服务"，请确认托盘图标存在，或手动运行一次 Ollama。
- 如果想换用其他模型（如 Llama、DeepSeek 等翻译效果较好的模型），
  同样使用 `ollama pull <模型名>` 下载即可，回到 GUI 点击「刷新模型」
  就能在下拉框中看到新模型。


【目录结构】
DocumentTranslator/（即本项目目录）
├─ 启动翻译器.bat        双击启动入口
├─ App/
│  ├─ engine/            程序源码
│  ├─ .venv/             自动创建的 Python 虚拟环境（首次运行生成）
│  └─ requirements.txt   依赖列表
├─ Data/
│  ├─ input/             建议把待翻译文件放在这里（非必须，浏览框可选任意位置）
│  ├─ output/            翻译结果输出目录
│  ├─ logs/              每次任务的日志
│  ├─ cache/             预留缓存目录
│  └─ config/            记住你上次选择的语言/模型/风格等设置
└─ 使用说明.txt           本文件

后续如果需要更新程序代码，只需替换 App/ 目录内容，Data/ 目录中的输出、
日志和配置会被保留。


【关于 SRT 字幕翻译】
- 输入 .srt 字幕文件，输出仍为 .srt，序号和时间轴保持不变，只翻译字幕文本。
- 程序会把多条字幕打包成一批一起发给模型翻译，速度比逐条翻译快很多；
  若某一批返回格式异常，会自动改为逐条翻译，不会影响其他字幕。
- 勾选「同时输出双语对照」时，bilingual.srt 中每条字幕会显示两行：
  第一行原文、第二行译文，时间轴不变（可直接当双语字幕加载）。


【当前版本的已知限制】
- DOCX / PDF 输入会被提取为纯文本后翻译，输出为 .txt（不保留原排版/样式）。
- 队列中的所有文件使用同一套「源语言/目标语言/模型/风格」设置，
  不支持逐文件单独设置；如需混合语言，可分批次添加并翻译。
- 不支持术语库、OCR 扫描识别（计划在后续版本中加入）。
- 翻译效果取决于所选本地模型的能力，模型越大通常质量越好但速度越慢。


【常见问题】
- 提示"未检测到 Python"：请安装 Python 3.10 及以上版本，安装时勾选
  "Add python.exe to PATH"，下载地址 https://www.python.org/downloads/
- 提示"未检测到 Ollama"：前往 https://ollama.com/download 安装。
- 提示"模型未安装"：按提示在命令行运行 `ollama pull <模型名>` 下载。
- 翻译速度很慢：可以换用更小的模型（如 qwen2.5:7b-instruct 或更小的
  3B 模型），或确认 Ollama 是否在使用 GPU（任务管理器中查看 GPU 占用）。
